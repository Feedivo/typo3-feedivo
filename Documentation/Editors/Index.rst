===========
For editors
===========

#. Open the page and add a new content element. The **Feedivo feed** element is
   listed under *Special elements*.
#. Pick a feed from the list. The list shows the feeds the connection covers;
   if it cannot be loaded, the reason is shown in its place and the feed ID
   from Feedivo can be entered in the fallback field.
#. Save. The page module shows the selected feed by name; the page shows the
   feed as designed in Feedivo.

The header, frame and other appearance options of the element work as in any
other content element.
